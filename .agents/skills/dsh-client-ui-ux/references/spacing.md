# 间距与分组

同一对象的标题、说明和操作应有清楚的归属。先在页面模型中分出页头、工具栏、列表和详情，再按重复行、字段组和操作组确定组内间距。优先使用现有基础类和项目间距 Token。[设计 Token](../../../../docs/design/tokens.md) · [页面模式](../../../../docs/design/patterns.md)

- 无显式分隔时，组间留白应明显大于组内。区块标题挨近自己的内容，筛选条件与对应的列表靠近，字段提示和校验错误紧贴字段。
- 相同角色的行、卡片与控件沿用同一套内距和节奏。遇到较长标题或多行提示时按内容重排，再检查相邻组间距和主操作位置。
- 连续工作区优先用对齐、留白和发丝线区分层级。表格、详情、弹窗和浮层沿用现有表面样式。
- 对比渲染后的空白时明确两端用文字边、线盒还是控件边。测量要包含内距、边框和行高。在桌面和窄屏检查标题换行、错误出现、浮层展开时分组是否仍然清楚。[对齐](alignment.md) · [浏览器验收](../SKILL.md#验收)
