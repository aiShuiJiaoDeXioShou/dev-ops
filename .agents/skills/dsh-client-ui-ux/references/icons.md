# 界面图标

先按操作含义查找本仓库的 shared 图标封装和 `lucide-react`。用控件已有的尺寸变体匹配同类入口。历史 `PrototypeIcon` 使用原型 Octicons，新增生产代码遵循 `@/prototype/*` 的依赖约束。需要新图形时放在适当的共享归属，按实际渲染尺寸与同类图标一起评估。[组件选择](../../../../docs/design/components.md#图标与品牌) · [品牌与能力目录素材](../../dsh-official-plugin-artwork/SKILL.md)

## 形态与位置

- 操作图标优先使用易辨认的单色轮廓，继承 `currentColor`。图标与对应的操作文字、搜索提示或值的下拉箭头共享前景色、透明度与状态变化。装饰图、状态图和品牌保持各自的语义，状态配文字。
- 比较点击区、可见按钮、SVG 槽位和绘制轮廓，分别检查居中、间距、裁切、线条粗细与相邻目标。常规对齐先改控件容器和槽位。修改共享 SVG 时核对所有受影响尺寸，特别是紧凑菜单和独立按钮。
- 自绘矢量使用易辨认的轮廓、留白和方向，沿用图标族的线宽、转角和端点。处理用户提供的图标时保留可辨认特征，在同一使用尺寸下比对原图、修改结果和相邻图标。涉及描边和缩放时核对 DPR 1 和 2 的实际显示。[对齐](alignment.md)

## 图标控件

- 图标按钮提供描述动作的 `aria-label` 和可见焦点。装饰性图标从可访问名称中排除。按钮的可点击区域至少 32×32px，移动端优先 44×44px。
- 图标含义或快捷键可用现有提示模式补充。重要解释通过键盘和触控都可打开的入口提供。触屏上的图标动作保持单次点击可用，提示遵循响应式技能。[响应式技能](../../dsh-responsive-ui/SKILL.md) · [交互规范](../../../../docs/design/interactions.md#9-可访问性)
- 在受影响的页面中检查图标的默认、选中、禁用和焦点状态，颜色变化时补看明暗主题。更换图标或调整尺寸时同时比对文字、点击区和相邻控件。[浏览器验收](../SKILL.md#验收)
