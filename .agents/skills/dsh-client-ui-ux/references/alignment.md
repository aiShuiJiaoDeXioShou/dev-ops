# 对齐

在目标页面或弹窗里确定对齐的对象和容器。导航文案、详情属性、正文标题和筛选控件各自使用同角色的阅读边。先对齐网格、列、边框和内距，再检查文字和图标的视觉位置。[UI 实现与验收](../SKILL.md)

| 场景                     | 对齐方法                                                           |
| ------------------------ | ------------------------------------------------------------------ |
| 侧栏、列表、详情         | 同层级文字共享起始线。工具栏和列表内容同时计入边框、图标槽位与间距 |
| 单行图标加文字           | 整组垂直居中。独立按钮在自身边界内居中图标和文字                   |
| 多行标题、混排字号       | 文字按基线，前置图标贴合所属首行。检查中英文、等宽文本和换行       |
| 标题与主操作、输入区两端 | 标题或输入组贴内容起始边，操作组贴结束边                           |
| 表格和重复操作           | 同列对齐相应的文字起点或控件中心，检查首行、末行及展开行           |
| 列表空态                 | 在页头和筛选之下的可用内容区居中。短视口用可滚动布局保留操作入口   |

图标的点击区、按钮轮廓、SVG 盒与绘制轮廓各有用途。增加点击区时保持布局槽位，避免相邻目标重叠。菜单选项与触发器或搜索结果的文字起点应计入侧边距、图标槽位和图标间距。

同一图标在多处都显得失衡时检查共享图标。只在特定组合有偏差时，先检查容器和槽位，确有需要再做局部视觉调整。在实际字号、宽度与状态下对照同类元素。[间距](spacing.md) · [图标](icons.md)
