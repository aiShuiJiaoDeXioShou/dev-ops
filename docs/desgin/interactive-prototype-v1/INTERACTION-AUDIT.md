# 原型模块交互审查

本原型通过群组、任务面板、运维计划与环境配置衔接日常工作。入口是[协作首页](http://127.0.0.1:4178/?v=20261108-30&page=collaboration)。以下结论针对本地 HTML 原型，不代表 Git 平台、模型或生产服务已经接入。

## 1. 审查范围与结果

实现位于 [app.js](app.js)、[workspace.js](workspace.js)、[styles.css](styles.css)、[workspace.css](workspace.css) 与 [文档快照页](template-preview.html)。审查依据是当前页面行为、源代码和浏览器操作验证。

| 模块 | 发现的问题 | 原型中的处理 | 核对路径 |
| --- | --- | --- | --- |
| 项目首页 | 只有名称与仓库，无法判断状态、工作量或进入重点事项 | 顶部晴雨表按日期呈现活动量；紧凑卡片集中展示阶段、负责人、完成度及模块数量；支持搜索、阶段筛选和直接进入模块 | 首页修改状态，再筛选；点击需求数字核对列表数量 |

| 环境变量与密钥 | 未区分环境、授权对象与使用方式 | 项目及环境隔离；请求、授权、轮换、撤销和记录；测试密钥不落盘 | 请求配置后恢复任务，撤销后不能继续 |
| 运维值守 | 只有产物展示，没有异常到处理的路径 | 日志事件去重建 Bug 和任务；规则启停与模拟触发 | 连续触发同类事件，核对一条问题和累计次数 |
| 运维变更 | 发布、数据库和清理缺少明确执行阶段 | 具体计划、确认、执行、核对、失败及重试 | 验收后制定计划，核对通过才更新运行版本 |
| 记忆与外部连接 | 长期信息及节点状态没有管理入口 | 项目记忆可修订、删除；连接配置显示未连接，节点可模拟离线 | 离线后开始任务得到明确反馈 |

## 2. 交互规则

活动晴雨表使用七行、53 周的日期网格，未来日期留空。颜色表示活动数量，来源可切换代码、事项、PR 和 Bots，并可点击日期查看分项。统计范围与当前项目搜索、阶段筛选一致。当前仅为确定性示例数据，不代表真实 Git 活动；新关联项目没有示例活动。

项目状态由成员维护，事项完成度按已完成事项除以全部事项计算。没有事项时显示 0 / 0。需求与 Bug 快捷数字统计未完成事项，进入列表时使用同一筛选规则；PR 数量统计待审核记录；Bots 数量统计项目内已启用的绑定，不将其解释为运行环境在线数量。

模板目录中的目标项目独立于正在查看的项目。编辑共享模板会增加版本号，已选用该模板的项目使用其当前内容。需要独立维护时创建副本。模板用于平台的协作约定，不自动写入远端仓库。

PR 记录与事项分开保存，同一 PR 可以关联多个事项。关联操作不会修改 PR 的标题、作者和远端状态，也不会改变事项的业务状态；首页统计按 PR 去重。

> **链接设计**
>
> 快照链接在片段中携带名称、版本与正文，预览页不依赖分享者的 localStorage。它能用于当前静态原型，但内容随链接携带，且不能撤回已复制的快照。生产版本应使用服务端发布记录和访问控制；本轮没有创建公网地址或共享服务。

复制成功后显示成功反馈；浏览器拒绝剪贴板权限时显示可手动复制的文本。下载生成真实文本文件，文件内容与当前查看版本一致。模板预览把正文作为文本显示，不执行其中的 HTML。

会话、草稿、模板和项目配置使用同一个浏览器本地存储。读取旧数据时补齐新增字段；存储失败时显示内存保留提示。浏览器地址只保存导航位置，不保存完整聊天正文。

## 4. 实现边界

- GitHub/Gitea 的实际授权、仓库读取、远端 Issue/PR 写入与错误恢复仍需真实后端实现。现有代码及差异为示例数据。
- 产物清单是可下载的本地文件，原型没有真实安装包、构建执行或部署功能。
- 角色权限在前端模拟，不能替代后端鉴权。
- 文档链接由当前站点地址和内容快照组成。127.0.0.1 链接不具备公网访问能力；生产发布、权限、撤回与长期版本历史需要单独实现。
- 值守仅手动演示，飞书仅本地预览，运维按钮不操作真实资源。密钥输入值丢弃，仅授权元数据保存在本地。
- 会话保存在当前浏览器，不支持跨设备同步。模板没有版本回滚或回收站；版本号用于识别当前内容。
