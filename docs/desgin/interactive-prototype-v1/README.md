# DevOps HTML 交互原型

本原型以独立 Bot 与群组会话为入口，通过授权的项目工具连接业务事项与运维操作，用于核对用户提出目标到结果验收的交互。产品要求见 [MVP 需求](../../../docs/prd/mvp.md)，逐模块核对见[交互审查](INTERACTION-AUDIT.md)。当前使用本地演示数据，未接入外部执行系统。

## 协作与任务

一级导航顺序为项目、协作、运维、能力和凭据库。协作默认打开不绑定项目的直接会话，会话列表顶部把搜索、新建和通知收在同一栏，通知中心以铃铛图标显示未读数量。新建菜单提供新建助手、新建群聊和新建文件夹；文件夹只做本地分组，会话可在设置中选择所属文件夹，删除文件夹不删除会话。项目默认进入需求，需求位于页签首位。项目协作直接展示按标签匹配的聊天和 Bots 群组及原聊天记录，不再跳转摘要页；无标签匹配时显示空状态。项目页不提供“全部标签”筛选、创建会话或聊天输入，无匹配时不自动创建群组。智能体定义、Skills、模板、记忆和连接配置统一放在能力中。

群组顶部显示名称、成员数量与 Leader；点击群名或设置按钮展开右侧设置，可调整职责、指令、成员和负责人，并管理工作标签。设置与任务面板互斥展示，不要求选择项目。“项目与工具”可添加零个或多个项目上下文；引用项目不会自动授权。成员变更不改动项目授权，更换 Leader 不自动转交任务；移出执行者会阻塞其未完成工作。全局智能体详情直接打开该 Bot 的会话。

输入区默认聊天，不自动新建任务。用户消息右对齐，Bot 正文左对齐；任务与工具记录折叠展示。“新任务”或加号菜单显式创建任务；选中任务后可切换“补充当前任务”。发送讨论消息会启动一条明确标注“本地模拟”的演示回复：流式正文、执行轨迹和耗时都由本地脚本生成，不调用模型或执行器，也不声称外部任务已经执行。使用 `@` 引用成员、仓库、文件、PR、事项或技能；未知引用、未加入上下文的项目资源，以及执行者未授权的仓库或技能不能提交。跨项目资源保留项目标识；权限按被选执行者校验。候选可点击选择；Enter 发送、Shift+Enter 换行、Escape 关闭候选。一次任务选择一位执行者。

任务面板显示业务负责人、执行者、环境、来源和交接记录。支持转交、开始、停止后续执行、重新开始、提交开发结果、请求配置及验收。需求或 Bug 详情的“交给 Bot 跟进”打开已有活动任务，或创建关联任务。任务执行状态与业务事项状态分别保存；验收通过后才将关联事项标记完成。

通用任务只需提交结果与完成情况；开发结果表单包含分支、提交、测试、产物与说明，模拟 CLI 或人工交付。测试通过后进入待验收，失败则受阻；验收后的发布计划是单独操作。原型不调用 CLI，也不追踪开发工具会话。

## AI 对话状态与上下文

会话头部按 DSH 的会话骨架提供“对话 / 轨迹 / 上下文 / 编队”四个页签，内部信息不再铺在聊天流里。对话页只保留消息、底部生成状态和消息操作；轨迹、附件与成员任务分别收进对应页签。页签角标显示轨迹次数、上下文数量和 Bot 人数，生成中的轨迹页签显示呼吸点。

“对话”页发送讨论消息后启动一条明确标注“本地模拟”的演示回复：顶部显示“深度求索中…”，输入框内的发送按钮切换为带旋转光环的停止按钮，底部状态条显示耗时与步数。执行轨迹在“轨迹”页签展示：按步骤给出开始时间、类型、摘要、耗时和状态，顶部有耗时概览条与运行切换，失败步骤和中断步骤分别标记；生成中可随时停止，已输出内容与部分轨迹保留。完成后可跳过动画、重新生成、复制、点赞或点踩、朗读。

“上下文”页签集中管理已添加的文件、链接、图片和页面批注，支持移除待发送附件、查看批注坐标与消息引用；输入框上方的附件标签横向滚动、不换行。页面批注会覆盖当前视图，悬停高亮页面元素，拖拽后弹出批注输入框，发送时把选框坐标、目标元素与批注文字打印为结构化 JSON 并转为本地附件。“编队”页签展示会话 Bot、Leader、模型与运行环境以及协作任务；项目协作只读视图保留页签查看，不提供发送或管理入口。

回复使用 Markdown 渲染标题、列表、引用、表格和代码块。代码块沿用 DSH 的浅色 banner：语言标签与复制、下载按钮为 11px，代码 11px/19px，长代码自动换行，关键字、字符串、注释和数字按浅色主题着色；复制后显示“已复制”。所有回复、轨迹和耗时均为本地演示，不调用模型或执行器。

## 项目工具

在会话点击“项目工具”，选择 Bot、目标项目和能力。可演示读取项目、修改代码、调用流水线、更新进度、提交 Bug、创建 PR／MR 草稿与添加评论。没有权限时显示缺失项，可以打开“项目能力授权”，明确保存后再调用；加入群组或引用项目不会替代授权。

调用结果保留在原会话，可查看参数和结果，并打开项目中的对应记录。代码示例保存在工作分支，默认分支不能直接覆盖；Bug、评论和进度更新同一份事项数据；PR／MR 仅创建本地草稿。流水线先显示运行中，再手动“演示运行完成”，结果在项目“流水线”页可见，不自动改变事项状态。

这些按钮用于核对工具调用体验，尚无模型自动选择工具、远端 Git 写入或真实 CI 执行。单次调用绑定一个目标项目，多项目工作通过多次明确调用完成。

## 运维与环境配置

运维提供运行概况、值守规则和变更记录。运行事件区域的“演示一次日志异常”创建关联 Bug 和排查任务；事件中的“查看处理链路”展示发现、建单、排查与发布验证，并可进入同一会话或 Bug。服务卡片按环境显示版本与健康状态。演示日志异常会聚合重复事件，并建立一条 Bug 和处理任务；任务未完成时再次触发增加次数。规则可以编辑、启停及手动演示触发，页面关闭后没有后台调度。

部署版本、数据库变更、服务器清理和云资源调整共用具体计划表单，记录环境、资源、范围、核对依据与恢复方案。流程为待确认、已批准、执行中、待验证、已完成；支持失败、核对状态后重试及执行前取消。部署验证通过更新演示服务版本。飞书只生成本地通知预览，不发送消息。

环境变量按项目及开发、测试、生产环境隔离，名称在同一环境内唯一。支持普通变量、密钥元数据、版本、Bot 授权、运行时注入或允许明文读取、当前任务／24 小时／长期授权，以及撤销和轮换。查看访问记录可以核对配置与授权动作。

任务提出缺失配置请求后进入等待配置。用户从请求打开配置表单，指定授权对象和期限；授权匹配且执行者可用后恢复演示任务。撤销权限会暂停依赖任务，其他环境或任务的授权不能替代当前授权。过期授权在继续任务时校验，原型没有后台过期调度。

**密钥值不保存、不发送、不回显。** 输入的测试值在提交或关闭表单后清除，仅保存名称、版本和授权元数据。普通变量会保存本地，因此不能用普通变量录入真实敏感值。真实密钥保险库、签发、注入和明文读取尚未实现。

## 团队与凭据库

当前默认使用管理员演示角色。团队管理可编辑名称和图标文字，创建邀请、模拟加入、调整角色及停用成员；不能降级或停用最后一位正常管理员。开发者和浏览者不能保存团队管理操作。邀请只写本地记录，不发送邮件。

团队切换位于侧栏最底部，图标为固定正方形，只有加入多个团队才显示。初始提供研发、产品两个演示团队，分别初始化示例数据；用户新增的会话、事项与凭据分别保存在各自团队存储中。旧版原型数据继续保留在研发团队，不复制到另一团队。

凭据库采用目录与详情双栏，支持 API 密钥、账号密码、SSH 密钥分类与搜索。管理员指定可用项目、Bot 与期限后，可引用到项目环境变量。引用不复制密钥，轮换更新版本；撤销后引用失效并阻塞依赖任务。项目页中的团队引用返回来源管理，不能通过项目表单扩大授权。

开发者可以提出配置请求。请求与管理记录收在右下角日志箱，默认只显示图标和待配置数量；点击打开大弹窗，可切换全部、配置请求和管理记录；长记录在弹窗内滚动，Escape 或关闭按钮收起。双栏凭据区填满页面可用高度。页面不再显示重复的大标题和说明，添加操作位于搜索框旁。复制操作仅复制 `keychain://团队/条目` 标识，不包含明文。输入的测试密钥提交或取消后丢弃；原型未连接操作系统密码服务或真实保险库。

## 项目、能力与文档

项目列表保留活动晴雨表、紧凑卡片、状态筛选与统计跳转。需求和 Bug 支持创建、编辑、筛选、讨论与提测；提测只改变业务状态。代码支持示例文件切换、复制和下载；PR 支持搜索、筛选和关联事项。产物页面分别展示构建产物、测试与生产版本，可下载版本清单，操作历史统一放在运维变更记录中。

智能体管理保留独立创建、配置、启停与项目能力授权。Bot 定义包含职责、负责人、头像、运行环境、模型和 Skills；项目能力按 Bot 与目标项目单独选择。Skills 不赋予工具或密钥权限，既有项目约定保留。停用、离线与缺少授权分别处理。

团队 Skills 支持发布、编辑、分类、检索、启停及 SKILL.md 复制和下载。“在 bots 中使用”选择已配置该技能的可用 Bot，直接进入会话并填入技能引用草稿，无需先选择项目。

AGENTS.md 支持全文预览、正文复制、下载、副本、版本和独立快照链接，选用时明确目标项目。快照保留分享时内容，当前本机链接不是公网发布服务。选用模板不修改远端仓库文件；密钥不得写入模板或分享链接。

记忆按项目与 Bot 维护，支持新增、编辑、确认和删除，保留来源及更新时间。当前为手工管理，未实现自动提取、压缩或检索。连接页面维护地址和凭据引用，保存后显示未连接；节点支持模拟离线与恢复，以验证任务阻塞。

本次参考的本机应用为 OpenBot 0.59.0，对应 [nightly-labs/openbot](https://github.com/nightly-labs/openbot)。仅核对安装元数据和公开说明，未接入或复制其运行代码；不宣称已覆盖其全部功能。

页面采用紧凑工具栏，去除重复页面大标题、装饰性英文和运维宣传横幅；项目名、会话名等实体名称与必要分组保留。

侧栏“能力”使用模块组合图标；“协作”黑色 Bot 轻微摇摆、眨眼，悬停和键盘聚焦时招呼。系统开启减少动态效果时静止显示。

群聊头像按实际启用成员展示，优先 Leader，最多四位：两位叠放、三位三角、四位四宫格。工作标签在全局会话设置中维护，可关联多个项目。项目相关性仅取决于会话或其中任务的标签与项目的关联，资源引用不等同于标签；整理标签不改变工具授权。

成功提交任务结果后，原型通过关键词规则模拟 Bot 复用或创建工作标签，并关联任务目标项目。失败结果不自动归档，验收不重复整理；人工可创建、选择和修改标签。尚未接入真实 Agent 分类或模型回复。旧标签仅从已关联任务恢复项目归属，不将历史资源引用静默转换成标签；未归类的历史会话仍完整保留在全局协作。

### 知识资产快照的生产边界（2026-11-10）

原型快照页把正文放在 URL 片段中，仅用于静态演示。正式页面使用服务端生成的随机令牌定位快照，打开链接仍要求登录与团队成员权限，页面设置 `Referrer-Policy: no-referrer`，不提供匿名公网访问、撤回或访问统计；模板编辑不改变已生成链接的内容。
