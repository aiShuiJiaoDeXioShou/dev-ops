# Web 项目管理平台 UI 基准稿 v1

本轮交付为三版 Image Gen 静态探索稿，尚未选定最终方向，尚未制作 Figma 可编辑稿或业务实现。

## 设计依据
- 用户指定 Web 平台、简洁风格，要求先生成几版基准稿。
- 用户提供 Mail Desk 截图作为风格参考，只借鉴应用区域，不沿用浏览器侧栏或邮件业务内容。
- Multica 官方定位：团队成员与 AI Agent 协作管理任务。来源：https://multica.ai/
- 临时产品名「项目工作台」，示例项目「Web 平台」。名称、任务和运行数据仅用于设计演示，不代表已确认需求。
- 本轮仅探索核心任务页面；权限、调度、工作流及其他页面范围后续确定。

## 三版方向
- A：分栏任务工作台。导航、任务列表、任务正文、属性与运行信息；最接近参考图，适合逐条处理任务。图片 a-task-workspace.png。
- B：紧凑任务列表。以表格、分组和右侧详情面板组织信息；适合多任务扫描与管理。图片 b-task-list.png。
- C：留白项目看板。以阶段列和任务卡片组织信息；适合观察项目进度与审核队列。图片 c-project-board.png。
- 建议以 A 定义整体视觉与详情交互，B 与 C 作为项目任务的两种可切换视图。

## UI 规范草案
以下为建议目标值，生成图片不代表已经精确执行这些尺寸。
- 默认桌面设计目标 1920 × 1200；实际图片尺寸以文件为准，后续至少校准 1440 与 1280 宽度。
- 背景 #F7F7F7；表面 #FFFFFF；主文字 #191919；次文字 #737373；分隔线 #E6E6E6。
- 主要按钮与选中导航使用近黑色，白字；状态强调色必须搭配文本或图标。
- 状态拟统一为：待开始灰色、进行中蓝色、待审核琥珀色、已完成绿色。Agent 在线状态用绿色圆点。当前候选图尚有差异，定稿时统一。
- 中文字体建议 PingFang SC / Noto Sans SC，西文字体 Inter / 系统无衬线。
- 正文 14px，辅助文字 12px，页面标题 22px；正文行高约 1.5。
- 8px 间距基准；按钮高度 36px；按钮圆角 8px；卡片圆角 12px；边框 1px。
- 导航宽约 208px；任务列表约 330px；属性侧栏约 300–350px；主要内容区自适应。
- 选中状态使用浅灰底或近黑导航块；键盘焦点需独立可见；悬停、禁用、加载、空状态与错误状态在选定方向后补全。
- 人类成员与 AI 使用同一负责人结构；AI 额外显示 AI 标记，任务状态与 Agent 运行状态分别表达。
- 任务详情侧栏在较窄屏幕改为抽屉；看板允许横向滚动，不能靠无限缩小文字容纳。
