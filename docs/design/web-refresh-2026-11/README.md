# Web 视觉修订：DSH 中性工作台（2026-11）

## 设计依据

本轮按 [DSH 风格探索稿 v3](../../desgin/web-dsh-style-v3/brief.md) 与官方 [Web UI style reference](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/web-styling.md) 收敛页面视觉，保留本项目既有 token 与交互规范：

- 连续白色工作区与浅灰侧栏，用发丝线分层，不堆叠浮动卡片与阴影。
- 蓝色只用于主操作、选中态与链接；中性选中底优先于彩色填充。
- 紧凑标题层级：页面标题 19px、区块标签 12–13px、正文 13–14px、辅助信息 11.5–12px；不广泛加粗。
- 行高与间距按 4px 基数；列表行 48px，工具条与筛选保持轻量。
- 详情面板独立滚动，属性与正文连续排布；主内容优先于能力说明与空态。
- 窄屏隐藏次要表格列，以标题 + 状态徽标完成主要识别；详情以整屏覆盖。

## 本次调整

- 侧栏：232px、分组标签（工作台 / 管理与设置）、38px 导航行、弱化底部边界。
- 项目工作区：压缩页头与页签；面包屑只保留“项目 / 当前页签”；需求/Bug 去掉重复列表标题，工具栏合并筛选、搜索与主操作；表格改发丝线、行高 48px、选中行使用中性选中底。
- 详情：增加固定工具条“需求详情 / Bug 详情 + 返回列表”，正文取消内层卡片，属性区收紧，页签改为下划线式。
- 代码页：代码浏览器上移到主内容区，写能力区块下沉，避免空区块占据首屏。
- 变更详情：主内容与属性分栏，属性区贴右；事件/执行记录使用发丝线卡片。
- 项目首页：晴雨表改为连续区块，项目卡片收紧统计区并移除未开放的 Bots 指标。
- 全局：筛选与搜索改为轻量表面；按路由设置 `document.title`；移动端列表与详情适配。

## 追加收口：状态与结构化信息（2026-11）

- 需求/Bug 状态从浅灰徽标改为圆点 + 语义色调（待处理/修复中/已解决/已取消等），列表与详情共用 `StatusBadge`，颜色只作辅助、文本始终可读；同时修正了 `.shell` 内 `--muted` 作为文字色导致的深底徽标问题。
- 产物与版本页「运行版本」改为按环境成行的结构化列表：环境、版本、核对状态、确认时间与操作分列，未知/待核对状态可读；失败态提供重试。
- 团队设置「执行节点」改为与 Git 连接同层级的设置卡片，展示在线/已注册/待连接数量，管理入口使用明确按钮。
- 列表分页改为计数在左、翻页在右，与表格共用发丝线。
