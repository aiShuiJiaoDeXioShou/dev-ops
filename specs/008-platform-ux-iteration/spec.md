# 功能规格：平台全量体验审计与自举迭代（第 1 期）

**创建日期**：2026-11-11

**状态**：已实现（本机验收）

## 定位

以「dev-ops 平台自身」作为自举项目，完整走一遍需求 → 开发 → 提测 → 测试 → 验收，并在过程中修复 Web、API 与 CLI 的体验问题。审计覆盖桌面 1440×1000 与移动 390×844，账号覆盖管理员、开发者与浏览者。

## 范围

1. **Web 项目工作区**：需求、Bug、代码、PR、产物与版本、环境变量。
2. **Web 平台页面**：导航与抽屉、项目列表与晴雨表、运维/变更、能力（Skills/模板）、凭据库、储存桶、团队与节点、个人资料、认证页。
3. **API 与权限**：统一响应信封、权限矩阵、业务冲突、幂等、错误日志与敏感信息。
4. **CLI**：全部命令组的可执行性、`--json`、退出码、参数校验与文档一致性。
5. **内置流水线**：仓库内 `.devops/workflows/platform-smoke.yml` 的真实运行、日志与产物。

## 不在本规格内

- Bot 协作（V0.5）、运行事件与值守（V0.6）及其页面。
- 外部执行系统连接器、真实生产部署。
- 头像上传、第三方技能导入等已登记待确认能力。

## 验收标准

- 审计问题清单中的 P0 全部修复；P1 按可实现范围修复，未完成项在 evidence 中保留。
- Web、服务端、CLI、Agent 测试通过；`pnpm ui:check` 无新增违规。
- 流水线在本地注册节点上成功运行并产出可下载产物。
- 需求状态完整流转（开发→提测→测试→通过），真实提交与 PR 在平台可查。
